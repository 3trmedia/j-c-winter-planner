# J&C Winter Planner

A standalone, single-page dashboard for J&C Asphalt's winter/off-season
marketing plan. Shows the shared October team goal, each person's
(Jeffrey, Kaden, Ben) individual goal, and a clickable calendar of
marketing milestones.

Split out from the `demo-dashboard` / J&C Command Center app — same
stack (React + TypeScript + Vite + Tailwind), no backend, all data is
local mock data in `src/App.tsx`.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
